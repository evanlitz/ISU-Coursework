# CS319 In-Class Activity 02 - HTML Tables

**Author:** Evan Litzer (bubaq@iastate.edu)
**Date:** September 3, 2025
**Course:** CS319 - Construction of User Interfaces, Iowa State University

## Overview

This project demonstrates HTML table construction and layout techniques through 20 progressively complex examples. The activity covers fundamental table attributes, cell spanning, nested tables, styling, and media integration.

## Files

- `bubaq_Activity02.html` - Main HTML file containing all table examples
- `Activity01Puppies.jpg` - Image asset used in media tables
- `comicallylargespoon.mp4` - Video asset embedded in Table 19
- `README.md` - This file

## Features Demonstrated

### Basic Table Construction
- Single and multi-cell tables
- Row and column structures
- Table borders, cellspacing, and cellpadding

### Cell Spanning
- `colspan` - Cells spanning multiple columns
- `rowspan` - Cells spanning multiple rows
- Combined colspan/rowspan layouts

### Styling & Formatting
- Inline CSS styling
- Text alignment (horizontal and vertical)
- Text formatting with `<strong>` and `<mark>` tags
- Fixed and proportional width columns

### Advanced Layouts
- Nested tables (tables within table cells)
- Complex multi-row, multi-column structures
- `nowrap` attribute for text control
- Table captions and headers

### Media Integration
- Image embedding with alt text
- Image grids
- Video embedding with playback controls
- Hyperlinks within table cells

## Usage

1. Clone or download this repository
2. Ensure all files are in the same directory:
   - `bubaq_Activity02.html`
   - `Activity01Puppies.jpg`
   - `comicallylargespoon.mp4`
3. Open `bubaq_Activity02.html` in any modern web browser

No build process, installation, or dependencies required.
