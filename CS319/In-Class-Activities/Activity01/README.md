## Description

This activity introduces basic HTML elements and structure. The webpage demonstrates:

- HTML document structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Heading hierarchy (`<h1>` through `<h4>`)
- Paragraphs (`<p>`)
- Line breaks (`<br>`)
- Unordered lists (`<ul>`, `<li>`)
- Image embedding (`<img>`)

## Files

- `Activity01Puppies.jpg` - Image file displayed in the webpage
